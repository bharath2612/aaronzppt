# Project status

Updated: 2026-11-10 17:54 +04 (Claude Code, Claude Opus 5.5). Latest session note: `docs/sessions/2026-11-10-1805-reem-problem-story.md`.

Aaronz is a static, offline-capable Reveal.js presentation about proposed UAE real-estate commission finance. It contains:

- the main deck (`index.html`, 26 slides), with an embedded earnings calculator and a fee-scenarios slide;
- a separate Imtiaz proposal deck (`imtiaz.html`, 8 slides);
- a standalone calculator page (`commission-calculator.html`).
- an investor deck (`investor/index.html`, 13 slides), a skeleton being filled in progressively;
- a financier brief for Reem (`reem/index.html`, 7 slides).

There's no backend or build pipeline. GitHub Pages publishes it from `main`: https://bharath2612.github.io/aaronzppt/.

## Code map

- **Main deck:** slides in `index.html`, styles in `assets/presentation.css`, navigation in `assets/presentation.js`.
  - Calculator logic: `assets/calculator.js` and `assets/unit-picker.js`.
  - Fee-scenarios slide: `assets/scenarios.js`.
- **Imtiaz deck:** `imtiaz.html` with styles in `assets/imtiaz.css`. It reuses `assets/presentation.js` and is set in the vendored Inter font.
  - Logos: `assets/brand/imtiaz-logo.svg` and `assets/brand/aaronz-co-logo.svg` (vector, traced from the site PNG). Scripts: `assets/imtiaz-select.js` (payout picker) and `assets/imtiaz-present.js` (Present button). PDF: `npm run export:imtiaz` writes `imtiaz.pdf` (`tools/export-imtiaz-pdf.cjs`).
- **Investor deck:** `investor/index.html` with `investor/investor.css`, which overrides the palette on top of `assets/imtiaz.css`. It also reuses `assets/presentation.js` and `assets/imtiaz-present.js`. Test: `tests/investor.cjs`.
- **Reem deck:** `reem/index.html` with `reem/reem.css`, on top of `investor/investor.css` (both linked with `?v=` hashes the test checks). Test: `tests/reem.cjs`. PDF: `npm run export:reem` writes `reem/aaronz-reem.pdf`.
- **Standalone calculator:** `commission-calculator.html` has its own inline copy of the calculation.
- **Global player data:** `assets/global-players.json`. The tables shown on the slides are embedded in the HTML.
- **Diagrams:** generated by scripts in `diagrams/` and rendered with `@excalidraw/cli` 0.2.0. Scripts: `create-roadmap.cjs`, `create-developer-flows.cjs`, `create-fee-scenarios.cjs`.
- **Tests:** `npm test` runs `tests/presentation.cjs`, `tests/imtiaz.cjs`, `tests/investor.cjs` and `tests/reem.cjs` (Playwright).
