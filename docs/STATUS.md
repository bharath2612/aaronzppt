# Project status

Updated: 2026-10-30 11:04 +04 (Claude Code, Claude Opus 5.5). Latest session note: `docs/sessions/2026-10-30-1104-channel-connect-review.md`.

Aaronz is a static, offline-capable Reveal.js presentation about proposed UAE real-estate commission finance. It has 26 slides, an embedded earnings calculator, a fee-scenarios slide and a standalone calculator page (`commission-calculator.html`). There's no backend or build pipeline. It's published by GitHub Pages from `main`: https://bharath2612.github.io/aaronzppt/.

## Code map

- Slide content is in `index.html` and styling in `assets/presentation.css`.
- Navigation is in `assets/presentation.js`; calculator logic is in `assets/calculator.js` and `assets/unit-picker.js`; the fee-scenarios slide uses `assets/scenarios.js`.
- `commission-calculator.html` has its own inline copy of the calculation.
- The global directory data is in `assets/global-players.json`; the tables shown on the slides are embedded in the HTML.
- Diagrams are generated by scripts in `diagrams/`, rendered with the official `@excalidraw/cli` 0.2.0:
  - `create-roadmap.cjs` → `aaronz-roadmap.*`
  - `create-developer-flows.cjs` → `aaronz-developer-flows.*`
  - `create-fee-scenarios.cjs` → `aaronz-fee-scenarios.*`

## Current state

- **Deck calculator.** Inputs: market or processed volume, **our interest rate (annual, default 12%)**, bank rate (6.59%), **developer payment duration (default 30 days)**, **commission advanced (default 100%)**, plus optional bank charges and the day-count basis.
  - The customer fee is read-only: our rate × days ÷ basis (1% by default).
  - Default result: AED 612.68K retained a year on AED 135.9M advanced.
