# Project status

Updated: 2026-10-29 23:32 +04 (Claude Code, Claude Opus 5.5). Latest session note: `docs/sessions/2026-10-29-2332-tracker-pitch-flows-calculator.md`.

Aaronz is a static, offline-capable Reveal.js presentation about proposed UAE real-estate commission finance. It has 25 slides, an embedded earnings calculator and a standalone calculator page (`commission-calculator.html`). There's no backend or build pipeline. It's published by GitHub Pages from `main`: https://bharath2612.github.io/aaronzppt/.

## Code map

- Slide content is in `index.html` and styling in `assets/presentation.css`.
- Navigation is in `assets/presentation.js`; calculator logic is in `assets/calculator.js` and `assets/unit-picker.js`.
- `commission-calculator.html` has its own inline copy of the calculation.
- The global directory data is in `assets/global-players.json`; the tables shown on the slides are embedded in the HTML.
- Diagrams are generated by scripts in `diagrams/`, rendered with the official `@excalidraw/cli` 0.2.0:
  - `create-roadmap.cjs` → `aaronz-roadmap.*`
  - `create-developer-flows.cjs` → `aaronz-developer-flows.*`
